# 🚀 Predictive Analytics for Customer Churn

### Aptura Tech Solutions - Data Science Internship (Batch 02) | Week 03 Project

An end-to-end **Machine Learning** project that predicts customer churn using the **IBM Telco Customer Churn Dataset**. This project demonstrates a complete production-style data science workflow, including data preprocessing, exploratory data analysis, feature engineering, model development, hyperparameter optimization, model evaluation, business insights, interactive deployment with **Streamlit**, and professional documentation.

The objective is to identify customers who are likely to leave a telecom company so that businesses can take proactive retention actions and reduce revenue loss.

# 🎯 Business Problem

Customer churn is one of the biggest challenges in the telecommunications industry. Acquiring a new customer is significantly more expensive than retaining an existing one.

The goal of this project is to build a predictive machine learning model capable of identifying customers who are at high risk of leaving the company, allowing businesses to implement targeted retention strategies and reduce revenue loss.

# 📈 Model Performance

Multiple Machine Learning algorithms were trained, compared, and evaluated using industry-standard performance metrics.

| Metric | Result |
|---------|--------|
| **Final Model** | Logistic Regression (Tuned) |
| **Test Accuracy** | **80.2%** |
| **ROC-AUC** | **0.841** |
| **Generalization Gap** | **~0.7%** |

The tuned **Logistic Regression** model achieved the best balance between predictive performance and generalization, making it the final production model.

### Models Evaluated

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
